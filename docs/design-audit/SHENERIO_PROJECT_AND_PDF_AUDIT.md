### Homepage order conflict and resolution proposal

Primary pp. 2–7 explicitly has ten sections ending with a **closing statement** after newsletter. Supplementary p. 6 lists the same first nine sections but ends with **luxury footer**. Preserve primary content: hero → House → collection → formulation → London/South Korea → everyday suitability/makeup → ritual → Journal → newsletter → closing statement → footer. Treat closing statement as the footer's introductory band if a ten-section CMS model is preferred. This is a proposed reconciliation, not permission to delete source content.

Newsletter source variants: primary p. 6 “STAY CONNECTED WITH SHENERIO.” / “JOIN THE SHENERIO COMMUNITY”; supplementary p. 4 “THE WORLD OF SHENERIO, DELIVERED.” / “SUBSCRIBE”. Use the primary pair on the homepage; supplementary pair on supporting subscription placements, retaining supplementary consent copy. Do not show two adjacent signup forms.
